# Capstone ハンズオン

Amazon Bedrock を活用したサーバーレス Web アプリケーションを構築する総合演習です。
各課題では、手順に沿ってアプリケーションを構築し、**課題パートでコードを完成**させてください。

---

## 課題一覧

### [課題 1: サーバーレスの生成 AI Web アプリケーションの構築](challenge1/README.md)

Bedrock の Converse API を使用して、ユーザーのプロンプトに対して基盤モデル（Amazon Nova Lite v1）が回答を生成するアプリケーションを構築します。

### [課題 2: サーバーレスの RAG アプリケーションの構築](challenge2/README.md)

Bedrock のナレッジベースと RetrieveAndGenerate API を使用して、企業の独自ドキュメントをもとに回答を生成する RAG アプリケーションを構築します。

---

## 共通アーキテクチャ

両課題とも以下のサーバーレスアーキテクチャで構成されています。

| サービス | 用途 |
|---------|------|
| Amazon S3 | Web ページのホスティング（構築済み） |
| Amazon API Gateway | REST API エンドポイント |
| AWS Lambda | バックエンド処理（Python 3.14） |
| Amazon Bedrock | 生成 AI（課題1: Converse API、課題2: ナレッジベース） |

---

## 進め方

1. **課題 1** から順番に取り組んでください。
2. 各課題の手順に従ってリソースを作成し、**課題パート**でコードを完成させます。
3. 動作確認まで行い、正しく動くことを確認してください。
4. 解答例は各課題の `solution` フォルダを参照してください。
